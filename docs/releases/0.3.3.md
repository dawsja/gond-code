Gond Code 0.3.3 adds light mode.

## New

- A Theme setting in Settings → General lets you choose System, Light or Dark. The default is System, so a computer set to light shows light mode after updating. Choose Dark to keep the old look.
- All seven tint colours work in light mode. The terminal palette and the Windows title bar follow the theme.

## Known issues

- The installer is not code-signed yet, so Windows may show a SmartScreen warning: choose More info, then Run anyway.
