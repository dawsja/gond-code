Gond Code 0.2.1 keeps your agents running when Gond Code closes, brings their conversations back after a restart of the PC, and plays a sound when one is done or needs you.

## Agents keep running

- Terminals now run in the background, so quitting, updating or a crash of Gond Code leaves every shell and the agent in it working. When Gond Code opens, each pane picks its terminal back up exactly as it was: its screen, its history and what it printed while you were away.
- Settings → General → Quitting can close the terminals when you quit instead. The tray's Quit and close all terminals always does.
- After a restart of the PC, a pane that was running Claude Code, Codex, Antigravity, Grok Build, opencode, Pi, GitHub Copilot or Cursor opens in the folder the agent was in and resumes its conversation with the agent's own resume command. Nothing is installed into the agents to do this.

## Sounds

- A chime when an agent finishes while you're in another pane or another app, and an alert when one asks you something. They play from the tray too, one after another when several come at once.
- Settings → General → Sounds turns them off.

## Panes

- Drag a pane by its header onto another: the middle swaps the two, an edge puts it beside that pane on that side. Esc cancels.
- Ctrl+Shift+F searches what every pane printed, in every session. Pick a match to jump to its line.
- A file:line a pane prints (src/main.rs:42) is a link: click it to open the file at that line in your editor. Settings → General → Open files in picks the editor.
- Drop files, folders or screenshots onto a pane to type their paths in, written the way that pane's shell expects.
- The command list (Ctrl+Shift+P) now runs its commands, not just lists them.

## Sidebar

- Each agent with a plan has a usage icon after its name, amber when a limit is low and red when one is used up. Hover it for every limit of the plan, what's used and when it resets.
- A warning when an agent's plan gets low, and when it runs out.

## Settings

- Settings → General → Terminal font: JetBrains Mono (the default), Hack or Fira Code Nerd Font.

## Fixes

- A new terminal no longer takes the focus from what you're typing in the sidebar or the command list.
- Needs you shows for an agent asking a question high up in a tall pane.
- Cursor's agent is recognised in its pane.

## Known issues

- Terminals open when you update to 0.2.1 start again as new shells, since 0.2.0 ran them inside the app. From 0.2.1 on, they keep running through updates.
- A restart of the PC still ends the agents; their conversations come back, not their running work.
- Gond Code isn't code-signed yet, so Windows SmartScreen may warn when you first install it. Choose More info, then Run anyway.
- An agent installed through npm runs as Node, so Gond Code doesn't see it in its pane: it works, but shows no status, gets no sounds and isn't resumed.
- Plan limits for Claude Code, Antigravity, Copilot and Cursor come from the same sources their own usage screens use. These aren't documented and may change; if they do, the bars keep their last reading.
