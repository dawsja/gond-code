Gond Code 0.2.0 makes every pane a terminal: you start an agent by typing it, signed in the way its own CLI already is.

## Panes

- Every new pane is your default shell. Ctrl+T, Split right and Split down open one beside the pane, in the same folder.
- Type `claude`, `codex` or any agent you've installed to start it. Gond Code sees it running: the pane shows the agent and what it's doing, and the sidebar lists it under Agents.
- Double-click the divider between two panes to even the split.
- A pane that ran an agent before this update opens as a terminal in its folder. Start the agent again with its own resume (`claude --continue`, `codex resume`) to pick the conversation back up.

## Pasting

- Ctrl+Shift+V with a screenshot or a copied image in the clipboard pastes it into Claude Code, Codex and the other agents.
- Pasting no longer asks for permission to see the clipboard.

## Settings

- Settings → Agents installs, updates and uninstalls the agents. Each agent signs in inside its own CLI.
- Settings → Usage shows each installed agent's plan limits, from its own sign-in.

## Removed

- The New agent dialog, with its sign-in, folder, model and direction choices.
- Accounts, API keys and model endpoints kept in Gond Code. The keys and sign-ins it saved for them are deleted when you update.

## Fixes

- A new terminal gets your current PATH, so an agent you installed after Gond Code started (Codex, for one) runs there without a restart.

## Known issues

- Gond Code isn't code-signed yet, so Windows SmartScreen may warn when you first install it. Choose More info, then Run anyway.
- An agent installed through npm runs as Node, so Gond Code doesn't see it in its pane: it works, but shows no status and gets no image paste.
- Plan limits for Claude Code, Antigravity, Copilot and Cursor come from the same sources their own usage screens use. These aren't documented and may change; if they do, the bars keep their last reading.
