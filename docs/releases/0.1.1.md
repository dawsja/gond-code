Gond Code 0.1.1 adds GitHub Copilot and Cursor, a status bar, and a new look.

## New agents

- GitHub Copilot: install it (winget, or Bun), update and uninstall it from Settings → Agents. Sign in with GitHub, add more GitHub accounts side by side, use a fine-grained GitHub token, or point it at your own model endpoint. Pick its model and how hard it thinks.
- Cursor: install, update and uninstall its command-line agent. It uses your Cursor sign-in, or a Cursor API key. Pick its model and how hard it thinks.
- Both pick their conversation back up after you restart or update Gond Code.
- Settings → Usage shows Copilot's monthly AI credits and Cursor's included usage (with its Auto and API shares), as their own usage screens do.

## Workspace

- A status bar under your panes: the git repository and branch the focused pane is in (or that it's a plain folder), following a terminal's `cd`, and Gond Code's version.

## Settings

- Settings → GitHub is now Settings → Plugins, with GitHub as its first plugin.
- Every agent you install from Settings → Agents is put on your PATH, so you can also run it from any terminal. Uninstalling takes it off again.
- An agent's "is ready" or "is uninstalled" line clears after a few seconds.

## Look

- A new Gond Code logo: the Gond bot's eyes as a terminal prompt. It's the app icon, in the title bar, the taskbar and the installer.

## Fixes

- In an agent's ⋯ menu, Uninstall now highlights across the whole menu like the other items.

## Known issues

- Gond Code isn't code-signed yet, so Windows SmartScreen may warn when you first install it. Choose More info, then Run anyway.
- The thinking level you pick for Codex isn't applied yet.
- An API key or token you give an agent can be read by the commands that agent runs.
- Plan limits for Claude Code, Antigravity, Copilot and Cursor come from the same sources their own usage screens use. These aren't documented and may change; if they do, the bars keep their last reading.
- Cursor keeps one sign-in per Windows user, so Gond Code can't hold two Cursor sign-ins side by side (API keys work).
