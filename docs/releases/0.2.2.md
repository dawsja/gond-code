Gond Code 0.2.2 fixes an agent that kept switching between Needs you and Idle, playing the alert again each time, and reads each agent's status more surely.

## Fixes

- An agent asking you something no longer switches between Needs you and Idle when you click another pane or another app, and no longer plays the alert over and over.
- An agent that ended its reply with a question ("Would you like to…") shows Idle, not Needs you. Needs you is for its real prompts: the choices it shows, a yes or no, Enter to confirm.
- A right-click in a pane running Claude Code opens the pane's menu without pasting into Claude Code. Paste is in the menu.

## Status

- Claude Code and Codex say what they're doing in the title they set, and Gond now reads it first: Working while they work, Needs you when Codex asks for action.
- A choice in the conversation above Claude Code's input box (a list in its reply, a tool's output) isn't taken for a question while the input box waits for you.

## Sounds

- A sound waits a second and plays only if the agent is still done or still asking, so a status that changes back and forth makes one sound at most.
