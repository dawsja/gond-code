Gond Code 0.1.0 is the first release: a Windows app that runs your coding agents side by side in a terminal workspace, each in its own command-line tool, exactly as it works in your terminal.

## Agents and sessions

- Claude Code, Codex, Antigravity, Grok Build, opencode and Pi, or a plain shell (PowerShell, Command Prompt, Git Bash, WSL).
- Group terminals into named sessions. Split panes right or down, resize, zoom, rename and restart them.
- The sidebar lists every agent across your sessions by what it's doing: needs you, working, done or idle.
- Ctrl+T starts an agent: choose how it signs in (your subscription or an API key), the folder, the model and how hard it thinks.
- Every agent picks its conversation back up after you restart or update Gond Code.

## Terminals

- Fast, GPU-drawn terminals with full 24-bit colour.
- A new session opens a terminal in your default shell, and each terminal keeps its shell.
- Ctrl+Shift+P lists every keyboard shortcut.
- Optional speech to text that runs on your PC: Ctrl+Shift+Space types what you say into the focused pane. The model is a 731 MB download when you turn it on.

## Settings

- Agents: install, update and uninstall each agent, with real progress and no console windows.
- Usage: each account's plan limits, as the agent reports them.
- GitHub: install Git and the GitHub CLI and sign in.
- Updates: Gond Code checks for new versions and restarts into one when you say so, with your sessions and panes where you left them.

## Known issues

- Gond Code isn't code-signed yet, so Windows SmartScreen may warn when you first install it. Choose More info, then Run anyway.
- The thinking level you pick for Codex isn't applied yet.
- An API key you give an agent can be read by the commands that agent runs.
- Plan limits for Claude Code and Antigravity come from the same sources their own usage screens use. These aren't documented and may change; if they do, the bars keep their last reading.
