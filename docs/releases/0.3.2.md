Gond Code 0.3.2 fixes Open folder and updates the app icon.

## Fixed

- Open folder in a pane's right-click menu now opens the terminal's current folder, even without a project or after changing folders. It is hidden for terminals on WSL or another computer, where Explorer cannot open that folder.
- Network paths shown in a terminal prompt are no longer used as the pane's folder, so a program cannot make Gond Code look at a network share.
- Prompts are read correctly in panes with a lot of history, so the status bar and Open folder follow the folder you are really in.

## Changed

- The app icon has a rounder frame to match the other Gond apps. The chevron and bar are unchanged. The updated icon appears in the taskbar, tray, window, installer and shortcuts.

## Known issues

- The installer is not code-signed yet, so Windows may show a SmartScreen warning: choose More info, then Run anyway.
