Gond Code 0.3.0 runs your terminals in WSL or on another computer over SSH, manages your SSH keys, and supports seven more agents.

## Machines

- A session's terminals can run in a WSL distribution or on another computer over SSH. Pick the machine with the switcher above Settings, Ctrl+Shift+M, or the command list.
- Agents on that machine show in the sidebar with their status, and pick their conversation back up after a restart, just like on this PC. Their terminals keep running if the connection drops, and Gond reconnects.
- Setting a WSL distribution as your default shell now works, and an agent you start there shows in the sidebar.
- Settings → Machines adds, edits and removes SSH machines. They're saved in ~/.ssh/gond/config, which your ~/.ssh/config includes, so `ssh <name>` works in any terminal too.
- When SSH asks something (a new machine's fingerprint, a password, a key's passphrase), Gond asks you.

## SSH keys

- Settings → Machines lists your SSH keys. Create one, with or without a passphrase.
- Set a key up on a machine in one click: Gond adds it to the machine's authorized_keys and checks you can sign in with it. Take it off a machine again, or delete it.

## More agents

- Droid, Kimi Code, MiniMax Code, Hermes Agent, Kilo Code, Devin and Cline. Install, update and uninstall each from Settings → Agents. Gond shows their status in the sidebar and resumes their conversations after a restart.
- Kimi Code's, MiniMax Code's and Hermes Agent's plan limits show in Settings → Usage.
- Updates are checked only for the agents you have installed, now opencode and Pi too.
- An agent that keeps a program running in the background (Cline, Hermes Agent) is stopped before an update or uninstall, so its files can be replaced.
- An agent whose files were left behind by an uninstall can still be uninstalled.
- Everything Gond knows about each agent now lives in one place, so when an agent changes how it installs or works, the fix is a small update.
