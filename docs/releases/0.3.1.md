Gond Code 0.3.1 focuses on seven agents and supports each of them fully: Claude Code, Codex, Antigravity, Grok Build, opencode, Pi and Devin.

## Agents

- Gond Code now supports Claude Code, Codex, Antigravity, Grok Build, opencode, Pi and Devin. GitHub Copilot, Cursor, Droid, Kimi Code, MiniMax Code, Hermes Agent, Kilo Code and Cline are no longer supported: they still run in a terminal, but Gond Code no longer installs, updates or tracks them.
- Devin's daily and weekly limits show in Settings → Usage and beside it in the sidebar.
- Grok Build is checked for updates like the others.

## Status

- Antigravity says when it's working, waiting for you or done, and the sidebar shows it.
- Grok Build's Working and Needs you come from its own title.
- opencode shows Needs you when it asks for permission, and Pi and opencode stay Working while they think, not only while text is coming.

## Fixes

- Pasting a picture into Pi or Grok Build with Ctrl+Shift+V now pastes the image.
